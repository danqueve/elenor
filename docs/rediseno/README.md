# Rediseño de Elenor (maquetas)

Maquetas de diseño en escritorio (1440 px), tablet (834 px) y celular (390 px): inicio, catálogo, ficha de producto y carrito.
Mantienen la identidad actual (paleta `brand-*`, Montserrat, un solo botón verde eléctrico por pantalla, menú inferior en móvil).

- Lienzo editable: <https://claude.ai/artifact/45P2BdxCGybcCVHnwSskBA>
- `canvas.json` es el índice del lienzo (posición y tamaño de cada pantalla); cada `*.dc.html` es una pantalla.
- Son referencia visual: no forman parte de la app Laravel ni se sirven desde `public/`.
- Los datos (productos, precios, teléfonos, mails) son de ejemplo.
